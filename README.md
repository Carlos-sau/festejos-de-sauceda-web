# Festejos de Sauceda

**Desarrollo y publicación de una página web para la Asociación Cultural Festejos de Sauceda.**

🌐 **Web publicada:** https://wordpressasociacioncfs.infinityfree.me/

## 📌 Sobre el proyecto

Este proyecto consiste en el desarrollo de una página web para la Asociación Cultural Festejos de Sauceda, con el objetivo de ofrecer un espacio online donde presentar la asociación, sus actividades y las fiestas del municipio.

La web se ha desarrollado con WordPress y Elementor, trabajando inicialmente en un entorno local y realizando posteriormente su migración a un servidor de hosting.

## 🛠️ Tecnologías y herramientas

- WordPress
- Elementor
- XAMPP
- MySQL
- phpMyAdmin
- FileZilla (FTP)
- InfinityFree

## 💻 Proceso de desarrollo

### 1. Desarrollo local
Instalación y configuración de WordPress en un entorno local mediante XAMPP. Diseño y personalización de las páginas con Elementor.

### 2. Gestión de la base de datos
Exportación de la base de datos MySQL mediante phpMyAdmin para trasladar el contenido y la configuración de WordPress.

### 3. Migración de archivos
Transferencia de los archivos de WordPress desde el entorno local al servidor remoto mediante FileZilla y el protocolo FTP.

### 4. Configuración del hosting
Configuración de la conexión a la nueva base de datos mediante `wp-config.php`, adaptación de las direcciones del sitio y configuración de HTTPS.

### 5. Publicación
Comprobación del funcionamiento de la página web en el dominio definitivo.
